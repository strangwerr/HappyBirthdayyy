# Happy Birthday, Swara 💗

A free, responsive birthday surprise website built with plain HTML, CSS, and JavaScript.

## Preview on your Mac

1. Download and unzip the website folder.
2. Open `index.html` in Chrome, Safari, or Firefox.
3. Click **Play our song** after adding your music file.
4. Tap the letter to open it and tap the cake to cut it.

## Add your pictures

Put four photos of you and Swara in `assets/photos/` and name them exactly:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`

JPG files work best. If your photo is PNG, either convert it to JPG or update the matching image filename in `index.html`. Keep photos you have permission to share.

## Add the birthday song

Put an MP3 file you have permission to use in `assets/music/` and name it:

`birthday-song.mp3`

The website will not start music automatically because browsers commonly block autoplay with sound. Swara can tap **Play our song** to start it.

## Personalize the message

Open `index.html` in a text editor and edit the text inside the letter section. You can change “your bestie” to your name or nickname.

## Publish for free with GitHub Pages

1. Create or sign in to a free GitHub account at https://github.com.
2. Create a new **public** repository, for example `swara-birthday`.
3. Upload the website files and folders (`index.html`, `style.css`, `script.js`, and `assets/`). Upload the files inside the project folder, not just the ZIP.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish. The website URL will appear on the Pages settings screen.

Your link will usually look like `https://YOUR-USERNAME.github.io/swara-birthday/`.

## Important privacy note

A public GitHub Pages site is visible to anyone with the link and may be discoverable. Only upload photos and music you are comfortable sharing publicly. Do not include private details, addresses, or anything Swara would not want online.

## Free options

GitHub Pages hosting is free for public repositories. You do not need to buy a custom domain. Google Fonts is optional; if internet access is unavailable, the website falls back to system fonts.
